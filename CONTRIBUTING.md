# Участие в разработке

Перед PR запустите `python3 -m unittest discover -q`, `python3 -m compileall -q .` и `python3 -m py_compile fancheck fanset`. Изменения регулирования сопровождайте проверками временных условий, аварийного поведения и ошибок оборудования. Тесты должны работать без GPU, root и запущенных служб.

В сообщении о совместимости укажите плату, чип hwmon, драйвер, модель GPU, версии HiveOS/Python и результат физической проверки корпуса. Чётко различайте испытания на оборудовании и моделирование. Не прикладывайте HiveShell-ссылки, токены, файлы с паролями, сведения об аккаунте, реальные UUID или полные конфигурации воркера.

Изменения не должны снимать действующие ограничения частот при остановке, автоматически принимать исчезновение карты или выбирать PWM по предположению. Зависимости времени выполнения желательно сохранять в пределах стандартной библиотеки Python.
